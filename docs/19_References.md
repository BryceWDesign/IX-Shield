# IX-Shield References

## Purpose
This reference list records the public-domain source lanes that informed the IX-Shield proof-of-concept architecture.

These references are used for architecture grounding and repository traceability.
Their presence does not mean IX-Shield reproduces any source verbatim, nor that IX-Shield is endorsed by any cited organization.

---
