# Contributing to IX-Shield

## Purpose
This repository is a concept-stage engineering package.
Contribution quality matters more than contribution volume.

## Contribution Posture
IX-Shield is not an open-source implementation repo.
It is distributed under an evaluation-only license.

That means:
- review and technical discussion are welcome;
- unrestricted implementation rights are not granted;
- operational use is not authorized by repository visibility alone.

## Preferred Contribution Types
The most useful contribution types are:

- technical issue identification;
- architecture critique;
- traceability corrections;
- documentation clarity improvements;
- bounded analysis improvements;
- reproducibility fixes.

## Contribution Types That Are Not Preferred
The following are not preferred without prior approval:

- sweeping redesigns presented as direct replacements;
- operational deployment claims;
- flight-readiness language;
- promotional language;
- speculative additions that weaken repository discipline;
- addition of restricted or non-public technical material.

## Ground Rules
All contributions should preserve the following rules:

1. do not overstate repository maturity;
2. do not introduce unsupported protection claims;
3. do not imply certification, human-rating, or operational approval;
4. do not remove non-claims or limitations language without strong justification;
5. do not add copyrighted, restricted, proprietary, export-controlled, or non-public material.

## How To Contribute
Preferred process:

1. identify a specific issue or improvement;
2. describe the problem clearly;
3. explain why the current repo package would be stronger if corrected;
4. propose a bounded change.

## Style Expectations
Contributions should aim for:
- technical seriousness;
- directness;
- traceability;
- bounded claims;
- clean repository structure.

Avoid:
- hype;
- marketing phrasing;
- miracle-material framing;
- generic positivity without technical substance.

## Repository Integrity Rule
A proposed change is weaker, not stronger, if it causes IX-Shield to look less honest about what it does not prove.

## Licensing Reminder
By contributing material, you represent that you have the right to provide it and that it does not violate the repository license or the rights of others.

## Final Note
The strongest contributions make the repository:
- more reviewable;
- more reproducible;
- more restrained;
- more technically coherent.
