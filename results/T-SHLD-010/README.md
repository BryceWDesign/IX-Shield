# T-SHLD-010 — Baseline Stack Screening

## Purpose
This result package group stores the processed outputs associated with the IX-Shield baseline stack screening run.

The baseline run exists to show that the repository can:
- load a machine-readable baseline stack;
- compute per-layer and total areal density;
- preserve the results in reviewable form.

## Included Run
- `RUN_SIMULATED_BASELINE_V1/`

## Analysis Scope
This package addresses concept-stage stack screening only.

It is intended to support:
- baseline configuration review;
- areal-density inspection;
- layer-contribution transparency.

It is not intended to provide:
- radiation transport validation;
- mission-certified dose analysis;
- operational shielding approval.

## Summary
T-SHLD-010 is the baseline stack screening result package for IX-Shield.
