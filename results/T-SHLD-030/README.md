# T-SHLD-030 — Zone Mass-Budget Screening

## Purpose
This result package group stores the processed outputs associated with the IX-Shield zone mass-budget screening run.

The zone run exists to show that the repository can:
- load a machine-readable zone reference configuration;
- compute concept-stage mass allocation totals and fractions;
- preserve the results in reviewable form.

## Included Run
- `RUN_SIMULATED_ZONE_MASS_BUDGET_V1/`

## Analysis Scope
This package addresses concept-stage geometry-aware mass-allocation screening only.

It is intended to support:
- zone configuration review;
- local mass distribution review;
- crew-core and refuge-adjacent mass reasoning.

It is not intended to provide:
- radiation transport validation;
- mission-certified shielding performance;
- operational authorization.

## Summary
T-SHLD-030 is the zone mass-budget screening result package for IX-Shield.
