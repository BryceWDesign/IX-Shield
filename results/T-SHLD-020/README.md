# T-SHLD-020 — Storm Shelter Screening

## Purpose
This result package group stores the processed outputs associated with the IX-Shield storm-shelter screening run.

The shelter run exists to show that the repository can:
- load a machine-readable shelter add-on configuration;
- compute concept-stage add-on areal density;
- estimate a simple water-equivalent proxy;
- preserve the results in reviewable form.

## Included Run
- `RUN_SIMULATED_STORM_SHELTER_10CM_V1/`

## Analysis Scope
This package addresses concept-stage shelter screening only.

It is intended to support:
- shelter add-on configuration review;
- local refuge enhancement review;
- target-comparison review using a simple water-equivalent proxy.

It is not intended to provide:
- radiation transport validation;
- mission-certified event analysis;
- operational shelter approval.

## Summary
T-SHLD-020 is the storm-shelter screening result package for IX-Shield.
